Installation
============

This :doc:`getting-started` guide is intended to assist the user with installing the library.


Install from PyPI
-----------------

The latest released version of :obj:`differences` can be installed from `PyPI <https://pypi.org/project/differences/>`_ using `pip`.

.. code-block:: console

   $ pip install differences


Import
------

Import the :obj:`differences` package in Python.

.. ipython:: python

   import differences
   differences.__version__
